# yet-another-survey (язь)

![Preview](preview.gif)

CLI + HTTP‑сервер для проведения и прохождения опросов. Сервер отдает JSON‑шаблон опроса/теста, клиент принимает его и запускает прохождение в терминале.

- Сервер на Drogon раздает шаблон опроса по HTTP.
- CLI‑клиент получает JSON и проводит опрос в терминале (если тест, то имеется валидация ответов).
- Примеры формата опросов и их хранения лежат в репозитории.

## Структура проекта
- `src` — исходники сервера и клиента.
- `include` — заголовочные файлы.
- `survey_templates` — примеры шаблонов опросов/тестов/ответов.
- `third_party` — сабмодули (Drogon и его зависимости).
  
ВАЖНО: если у вас нету папки `build`, то надо ее создать в корне проекта, пока что она в `gitignore`, в следующих коммитах пофиксим.

## Быстрый старт

### 1) Подтянуть сабмодули
```bash
git submodule update --init --recursive
```

ВАЖНО: не запускайте `cmake .` в корне — это создаст изменения внутри сабмодулей. Используйте только `cmake -S . -B build`.

### 3) Проверить, установлен ли Qt
Для графического интерфейса необходимо установить Qt, подробнее, как это делается, указано в `DOCUMENTATION.md`

### 2) Сборка
```bash
cmake -S . -B build
cmake --build build --parallel
```

Если вы случайно запускали `cmake .`:
```bash
cd third_party/drogon
git clean -fdx
cd ../..
```
больше так не запускайте :D

### 3) Запуск
Сначала сервер, потом клиент.

Сервер (слушает `127.0.0.1:8080`, по директории `/file` отдает JSON опроса):
```bash
./build/server
```

Клиент (получает JSON и запускает опрос):
```bash
./build/cli
```

## Что нужно для опроса?
По образу и подобию `test_survey.json` можно создать свой опрос и запуститься, а так же раздавать его с сервера, поменяв пути в `server_main.cpp`.
